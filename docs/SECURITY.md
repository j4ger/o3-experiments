# 安全与授权声明

本仓库内容仅用于**本人拥有设备**上的安全研究、互操作性分析与设备自用。

1. **范围**：研究对象是 Xiaomi 18 Fold（`lhasa`）上的 AIService 本地模型链路、
   厂商 NPU 运行时与 root 路径。不针对任何第三方设备、账号或服务。
2. **已识别的权限绕过**（`headers.uid=1000`、`sendTask` 无服务端鉴权、
   `DownloadProvider` 只读但同样可被短路）属于**本地授权绕过**。按负责任披露原则：
   先向小米安全响应中心报告，再决定是否公开细节；本仓库当前作为私有研究记录。
3. **root / 内核利用**：`apps/o3root` 集成的 o3root payload（CVE-2026-98260）会修改内核内存、
   加载未签名内核模块（KSU LKM），**仅当次开机有效**，可能导致崩溃、数据丢失、
   保修失效，并使设备处于 taint 状态。只在自己拥有且可承受重置的设备上运行。
4. **模型与数据**：本地 `artifacts/`（已在 .gitignore 中，不入库）不含任何用户数据；模型文件仅记录元数据/哈希，
   未归档权重本体（体积与版权原因）。
5. **合规**：在所在司法辖区或设备/运营商条款下，上述操作可能违法或违约；
   合规责任由使用者自负。
